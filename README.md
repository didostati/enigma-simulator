# Enigma Simulator

ენიგმას შიფრაციის მანქანის სიმულატორი ძველი გაზეთის თამაშით.
შექმნილია Python-ზე, როგორც AI Engineering with Python კურსის შუალედური პროექტი.

## იდეა
მოთამაშემ ჯერ გაზეთის ტექსტიდან უნდა გამოიცნოს სიტყვა.
გამოცნობილი სიტყვის პირველი სამი ასო ხდება როტორების საწყისი პოზიცია,
და მხოლოდ ამის შემდეგ მუშაობს მანქანა სწორად.

## გაშვება
```bash
python main.py
```

## სტრუქტურა
- `enigma/` — მთავარი პაკეტი (კომპონენტები, მანქანა, თამაში, ფაილები, ვალიდაცია, ინტერფეისი)
- `data/` — გაზეთის ტექსტები
- `docs/` — პროექტის მოთხოვნები
