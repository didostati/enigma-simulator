# Enigma Simulator

ენიგმას შიფრაციის მანქანის სიმულატორი ძველი გაზეთის თამაშით.
შექმნილია Python-ზე (tkinter), როგორც AI Engineering with Python კურსის შუალედური პროექტი.

## იდეა
მოთამაშემ ჯერ გაზეთის ტექსტიდან უნდა გამოიცნოს საკვანძო სიტყვა.
გამოცნობილი სიტყვის პირველი სამი ასო ხდება როტორების საწყისი პოზიცია,
და მხოლოდ ამის შემდეგ მუშაობს მანქანა სწორად: გაზეთის შიფრირებულ
შეტყობინებას სწორად გაშიფრავს.

## გაშვება
Python 3.10 ან უფრო ახალი ვერსია. გარე ბიბლიოთეკები საჭირო არ არის
(tkinter Python-თან ერთად მოდის). პროექტის ძირითადი ფოლდერიდან:

```bash
python main.py
```

## როგორ ვითამაშოთ
1. წაიკითხე გაზეთის სტატია და იპოვე მასში საკვანძო სიტყვა (3 მცდელობა).
2. ჩაწერე სიტყვა (მხოლოდ ლათინური ასოები A-Z) და დააჭირე "შემოწმება".
3. სწორი ვარაუდის შემდეგ "გაგრძელება" გახსნის ენიგმას მანქანას.
4. აკრიფე შიფრირებული შეტყობინება (ან დააჭირე "ავტომატურად ჩაწერე") და
   მანქანა გაშიფრავს. სურვილისამებრ დაამატე პლაგბორდის კაბელები.
5. ღილაკი "ისტორია" აჩვენებს ყველა წინა რაუნდის შედეგს; ჩანაწერის წაშლა
   ან მთელი ისტორიის გასუფთავებაც შეიძლება.

## შესაძლებლობები
- ენიგმას მანქანა: სამი როტორი (I, II, III), რეფლექტორი B, პლაგბორდი (მაქს. 10 კაბელი),
  როტორების ნამდვილი ბრუნვა (double-stepping-ის ჩათვლით);
- გაზეთის თამაში: სტატიები იკითხება `data/newspaper.json`-იდან და ვალიდირდება;
- შედეგების შენახვა ფაილში (`data/saves/results.json`) და ისტორიის ფანჯარა;
- ყველა შეყვანა ვალიდირდება, შეცდომა ეკრანზე ჩანს და პროგრამას არ აჩერებს.

## სტრუქტურა
- `main.py` — შესასვლელი წერტილი (ფანჯარა და ეკრანების გადართვა)
- `enigma/` — მთავარი პაკეტი:
  - `components.py` — პლაგბორდი, როტორი, რეფლექტორი (OOP)
  - `machine.py` — სრული მანქანა
  - `game.py` — თამაშის ლოგიკა (ინტერფეისის გარეშე)
  - `storage.py` — შედეგების შენახვა, წაკითხვა, წაშლა
  - `newspaper.py` — გაზეთის ეკრანი
  - `machine_view.py` — მანქანის ეკრანი
  - `history_view.py` — ისტორიის ფანჯარა
- `data/` — გაზეთის სტატიები (`newspaper.json`); `data/saves/` პროგრამა თავად ქმნის
- `docs/` — დეტალური აღწერა: `PROJECT_STRUCTURE.txt`
- `tests/` — ამ ეტაპზე ცარიელია; თვითშემოწმებები ცალკეულ ფაილებშია
  (`python -m enigma.storage`, `python -m enigma.game`, `python -m enigma.machine`)
