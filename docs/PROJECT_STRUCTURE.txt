==== main.py ================================================================================
დანიშნულება: პროგრამის შესასვლელი წერტილი. ქმნის მთავარ ფანჯარას, ტვირთავს სტატიებს და
ცვლის ეკრანებს (გაზეთი <-> მანქანა).

ფუნქციები:
  clear_window(window)
      შლის ფანჯარაში არსებულ ეკრანს, რომ მის ადგილას ახალი გამოჩნდეს.
  show_newspaper(window, articles)
      აჩვენებს გაზეთის ეკრანს. სწორი ვარაუდისას გადადის მანქანის ეკრანზე.
  show_machine(window, articles, article, word)
      აჩვენებს მანქანის ეკრანს გამოცნობილი სიტყვით; ღილაკი "უკან" გაზეთზე აბრუნებს.
  main()
      ქმნის ფანჯარას, ტვირთავს სტატიებს (შეცდომისას აჩვენებს შეტყობინებას და იხურება)
      და უშვებს window.mainloop()-ს.


==== enigma/components.py ===================================================================
დანიშნულება: ენიგმას მანქანის ძირითადი კომპონენტები. აქ არის OOP-ის სამივე პრინციპი:
ინკაფსულაცია (_ ცვლადები და property), მემკვიდრეობა (Component-დან) და პოლიმორფიზმი
(ყველა კლასს აქვს encode).

კონსტანტები:
  ALPHABET, ALPHABET_SIZE   ანბანი A-Z და მისი სიგრძე (26)
  ROTOR_SPECS               როტორების I, II, III გაყვანილობა და notch ასო
  REFLECTOR_B_WIRING        რეფლექტორ B-ს გაყვანილობა
  MAX_PLUG_PAIRS            პლაგბორდზე მაქსიმუმ 10 კაბელი

კლასები და ფუნქციები:
  EnigmaError
      ჩვენი საკუთარი შეცდომა არასწორი მონაცემებისთვის.
  letter_to_index(letter)
      ასოს გადაყავს ინდექსად (A=0 ... Z=25); არასწორისას EnigmaError.
  index_to_letter(index)
      ინდექსს გადაყავს ასოდ.
  validate_wiring(wiring)
      ამოწმებს, რომ გაყვანილობა არის 26 განსხვავებული ასო.
  Component
      საბაზო კლასი; encode(index) მემკვიდრეებმა უნდა გადაფარონ.
  Plugboard(Component)
      __init__()               ქმნის ცარიელ წყვილების ლექსიკონს
      add_pair(first, second)  ამატებს კაბელს (ვალიდაციით: არა თავის თავთან, არა ორჯერ, მაქს. 10)
      clear()                  შლის ყველა კაბელს
      get_pairs()              აბრუნებს წყვილების სიას, მაგ. [('A','B')]
      encode(index)            თუ ასოს აქვს წყვილი, ცვლის; თუ არა, უცვლელად ტოვებს
  Rotor(Component)
      __init__(name, wiring, notch, position)
      name                     property: როტორის სახელი
      position                 property + setter: მიმდინარე პოზიცია (A-Z)
      at_notch()               True, თუ როტორი notch-ის პოზიციაზეა
      step()                   როტორს ერთი ნაბიჯით ატრიალებს
      encode_forward(index)    სიგნალი პლაგბორდიდან რეფლექტორისკენ
      encode_backward(index)   სიგნალი რეფლექტორიდან უკან (შებრუნებული გაყვანილობით)
      encode(index)            პოლიმორფიზმი: წინა მიმართულების ტოლფასია
  Reflector(Component)
      __init__(wiring)         ამოწმებს, რომ გაყვანილობა წყვილებისგან შედგება
      encode(index)            სიგნალს უკან აბრუნებს
  create_rotor(name, position)
      ქმნის ისტორიულ როტორს სახელით ("I", "II", "III").

ფაილის პირდაპირი გაშვებისას (python enigma/components.py) მუშაობს მცირე თვითშემოწმება.


==== enigma/machine.py ======================================================================
დანიშნულება: ენიგმას სრული მანქანა. აერთიანებს პლაგბორდს, სამ როტორს და რეფლექტორს.
სიგნალის გზა: კლავიში -> პლაგბორდი -> მარჯვენა -> შუა -> მარცხენა როტორი -> რეფლექტორი
-> მარცხენა -> შუა -> მარჯვენა -> პლაგბორდი -> ნათურა.

კლასი EnigmaMachine:
  __init__(rotor_names, positions, plugboard)
      ქმნის მანქანას; ამოწმებს, რომ როტორები სამი და განსხვავებულია.
  positions                property + setter: სამივე როტორის პოზიცია ერთ სტრიქონად ("ABC")
  plugboard                property: წვდომა პლაგბორდზე
  _step_rotors()           როტორების ბრუნვა (double-stepping-ის ჩათვლით)
  encode_letter(letter)    შიფრავს ერთ ასოს (ჯერ როტორები ბრუნავს, მერე სიგნალი გადის წრეს)
  encode_text(text)        შიფრავს ტექსტს; არა-ასოები (ინტერვალი, ნიშნები) უცვლელი რჩება

ფაილის პირდაპირი გაშვებისას მუშაობს თვითშემოწმება (AAAAA -> BDZGO, double-stepping და სხვ.).


==== enigma/game.py =========================================================================
დანიშნულება: გაზეთის თამაშის ლოგიკა, ინტერფეისის გარეშე. ნებისმიერი ინტერფეისი (კონსოლი,
tkinter) ამ ფუნქციებს იძახებს.

კონსტანტები:
  PROJECT_DIR, DATA_PATH   გზა data/newspaper.json-მდე
  REQUIRED_KEYS            სტატიის სავალდებულო ველები: title, text, secret_word, message
  DEFAULT_ROTORS           ("I", "II", "III")
  MAX_ATTEMPTS             მცდელობების რაოდენობა ერთ რაუნდში (3)

ფუნქციები:
  extract_words(text)
      ტექსტიდან იღებს სიტყვების სიას დიდი ასოებით.
  key_from_word(word)
      სიტყვის პირველი 3 ასო = როტორების საწყისი პოზიცია; არასწორისას EnigmaError.
  validate_article(article, index)
      ამოწმებს ერთ სტატიას (ველები, საკვანძო სიტყვა ტექსტშია, შეტყობინება სწორია).
  load_articles(path)
      კითხულობს სტატიებს JSON ფაილიდან და ამოწმებს თითოეულს. შეცდომისას EnigmaError.
  pick_article(articles)
      შემთხვევითად ირჩევს ერთ სტატიას.
  encrypt_message(article, rotor_names)
      აშიფრავს სტატიის საიდუმლო შეტყობინებას საკვანძო სიტყვის გასაღებით.
  check_guess(article, guess, rotor_names)
      ამოწმებს ვარაუდს; აბრუნებს (გაშიფრული ტექსტი, წარმატებულია თუ არა).
  play_round(articles, max_attempts)
      ერთი რაუნდი კონსოლში.
  run_self_test(articles)
      ავტომატური შემოწმება ყველა სტატიაზე.

ფაილის პირდაპირი გაშვებისას: ჯერ თვითშემოწმება, მერე ერთი რაუნდი კონსოლში.


==== enigma/newspaper.py ====================================================================
დანიშნულება: გაზეთის ეკრანი (tkinter). მხოლოდ გამოსახავს; ლოგიკას game.py-დან იძახებს.

კონსტანტები: ფერები (PAPER_COLOR, INK_COLOR, ...), FONT_FAMILY ("Sylfaen"), CODE_FONT,
WRAP_WIDTH.

რაუნდის დასრულებისას (სწორი ვარაუდი ან მცდელობების ამოწურვა) შედეგი ინახება
storage.save_result-ით. შენახვის შეცდომა ეკრანზე ჩანს, მაგრამ თამაშს არ აჩერებს.

კლასი NewspaperScreen(tk.Frame):
  __init__(parent, articles, on_solved)
      on_solved(article, word) გამოიძახება სწორი ვარაუდისას.
  _build_widgets()          ქმნის და ალაგებს ეკრანის ყველა ელემენტს
  start_round()             იწყებს ახალ რაუნდს (ირჩევს სტატიას, აბრუნებს საწყის მდგომარეობას)
  _set_article_text(text)   ათავსებს სტატიის ტექსტს (წასაკითხი, მაგრამ კოპირებადი ველი)
  _update_attempts()        განაახლებს დარჩენილი მცდელობების წარწერას
  _show_message(text, color) აჩვენებს შეტყობინებას მოცემული ფერით
  _finish_round()           რაუნდის დასრულებისას კეტავს ველს და ღილაკს
  _save_round(guess, success)  ინახავს შედეგს storage.save_result-ით (EnigmaError-ს აჩვენებს ეკრანზე)
  _on_submit(event)         ამოწმებს ვარაუდს (check_guess); არასწორი ფორმატი მცდელობას არ ხარჯავს
  _on_continue()            გადასცემს გამოცნობილ სიტყვას გარე ფუნქციას (მანქანის ეკრანისთვის)
  _open_history()           ხსნის ისტორიის ფანჯარას (HistoryWindow)


==== enigma/machine_view.py =================================================================
დანიშნულება: ენიგმას მანქანის ეკრანი (tkinter): როტორები, ნათურები, კლავიატურა,
პლაგბორდი. შიფრვას თავად არ აკეთებს, EnigmaMachine-ს იძახებს.

კონსტანტები: ფერები, KEY_ROWS (QWERTZ განლაგება), LAMP_DURATION_MS, WRAP_WIDTH.

ფუნქცია:
  allow_one_char(new_text)  Entry-ის ვალიდაცია: ველში მაქსიმუმ ერთი სიმბოლო

      _refresh()            განაახლებს როტორებს, ტექსტებს და გაშიფვრის სტატუსს

==== enigma/storage.py ======================================================================
დანიშნულება: თამაშის შედეგების შენახვა ფაილში. მხოლოდ ფუნქციებია (UI არ არის). აქ არის
ფაილებთან მუშაობის სამივე ოპერაცია: შექმნა/რედაქტირება, წაკითხვა და წაშლა.

time, title, guess, success, attempts_left.

კონსტანტები:
  PROJECT_DIR, RESULTS_PATH   გზა data/saves/results.json-მდე

ფუნქციები:
  ensure_saves_dir(path)

      ფაილზე EnigmaError.
  _write_results(results, path)
      შიდა დამხმარე: ჩაწერს მთელ სიას ფაილში (ძველი შიგთავსი იცვლება).
  save_result(title, guess, success, attempts_left, path)
      ამატებს ერთ შედეგს (ფაილს ქმნის, თუ არ არსებობს). ვალიდაცია: სათაური არაცარიელი
      ტექსტი, success bool, attempts_left არაუარყოფითი მთელი. ვარაუდი ინახება დიდი ასოებით.
  delete_result(index, path)
      შლის ერთ ჩანაწერს ნომრით (0-დან); არასწორ ნომერზე EnigmaError.
  clear_results(path)
      შლის შედეგების ფაილს მთლიანად; აბრუნებს True-ს, თუ ფაილი იყო.
  format_result(result)
      ერთ ჩანაწერს აქცევს ერთ სტრიქონად ეკრანზე საჩვენებლად.
  run_self_test()
      ავტომატური შემოწმება დროებით ფაილზე (რეალური შედეგები არ ზიანდება).

თვითშემოწმების გაშვება პროექტის ძირითადი ფოლდერიდან:  python -m enigma.storage

==== data/newspaper.json ====================================================================
დანიშნულება: სტატიების მონაცემთა ბაზა. სია, რომლის თითო ელემენტს ოთხი ტექსტური ველი აქვს:
  title        სტატიის სათაური
  text         სტატიის ტექსტი (საკვანძო სიტყვა აუცილებლად უნდა შედიოდეს მასში)
  secret_word  საკვანძო სიტყვა (მხოლოდ A-Z, მინიმუმ 3 ასო); პირველი 3 ასო = გასაღები
  message      საიდუმლო შეტყობინება (მხოლოდ A-Z და ინტერვალი)

  CITY MARKET      საკვანძო სიტყვა HONEY    -> გასაღები HON
  RAILWAY NOTICE   საკვანძო სიტყვა RAILWAY  -> გასაღები RAI
ახალი სტატიის დასამატებლად საკმარისია JSON-ში ოთხივე ველის მქონე ობიექტის დამატება;
ვალიდაცია game.py-ში ავტომატურად შეამოწმებს მას.
